# Study Sky — PWA

Утсан дээр апп шиг суулгадаг хувилбар. Интернэтгүй үед ч ажиллана. Цаг агаарыг Open-Meteo-оос шууд татна.

## GitHub Pages дээр байршуулах (нэг удаа, ~10 минут)
1. https://github.com руу орж үнэгүй бүртгэл нээнэ.
2. Баруун дээд буланд байгаа **+** → **New repository** → нэр: `study-sky` → **Public** → **Create repository**.
3. **uploading an existing file** холбоосыг дарж, энэ хавтас доторх бүх файлыг чирч оруулна
   (`index.html`, `manifest.webmanifest`, `sw.js`, `icons` хавтас). → **Commit changes**.
4. **Settings** → зүүн талын **Pages** → *Branch* хэсгээс `main`, `/ (root)` сонгоод → **Save**.
5. 1–2 минутын дараа `https://<таны-нэр>.github.io/study-sky/` хаягаар нээгдэнэ.

## Утсан дээр суулгах
- **iPhone:** Safari-аар хаягаа нээ → **Share** → **Add to Home Screen**.
- **Android:** Chrome-оор нээ → **Install app** (эсвэл ⋮ → **Add to Home screen**).

## Өгөгдөл
- Даалгавар, хуваарь тухайн төхөөрөмж дээр хадгалагдана.
- Өөр төхөөрөмж рүү шилжүүлэх: доод хэсгийн **Save a copy** → файлаа нөгөө төхөөрөмж рүү явуулаад → **Load a copy**.

## Шинэчлэх
Засвар орсон `index.html`-ийг GitHub дээр дахин upload хийхэд утсан дээрх апп дараагийн нээлтээр шинэчлэгдэнэ.
